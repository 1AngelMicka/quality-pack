# Generic clusters — list dated 2026-11

Generated interfaces converge on the most probable "safe" design. Each round of anti-generic advice creates a new default, so this list is dated and must be revised. Use it to notice a default, never to pick a replacement: derive the choice from the brief and the references instead.

`sw look` measures most of these signals in the browser and weights them. One signal alone is never a defect; in `operate` mode, a conventional layout is right and only quality signals count.

## Tokens

- Inter, Geist, Roboto or the system font setting nearly all the text, chosen by default rather than for a reason.
- An indigo or violet primary (hue 240–290°), purple-to-blue gradients, gradient text in headings.
- Glass panels (backdrop blur), coloured glows, one soft shadow everywhere.
- One radius (12–24 px) on every box.
- Newer defaults that came from earlier advice: cream background with a terracotta accent; near-black with an acid-green accent; the "broadsheet" editorial look; a serif italic word inside a sans-serif headline; Space Grotesk as the "distinctive" font.

## Composition

- A centred hero with a pill badge above the headline and two buttons.
- Three identical cards with an icon, a title and a line each; "1-2-3" steps; a row of big statistics.
- Uppercase "eyebrow" labels above every section title.
- The same fade-up animation on every section.
- Emoji used as icons in headings, buttons and navigation.

## Content

- Hollow wording (the pack's list in `referential/slop-words.yaml`): "seamless", "unlock", "elevate", "revolutionary", "effortless", "not just X, but Y".
- Invented testimonials, a "Trusted by" row of logos without permission, figures without a source.

## What works instead

- A reference with real depth beats any rule: in one test, every run given a concrete reference avoided the generic look, while no instruction-only skill did.
- One signature element, chosen from the subject of the product, and boldness spent in that one place.
- Real content: the product's own screens, real photographs, real numbers, the client's voice.
- Finish the last ten per cent: alignment, spacing on the scale, states, empty states.
